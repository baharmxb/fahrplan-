# Fahrplan

اپلیکیشن فارسی و راست‌چین برای اجرای برنامه‌ی روزانه‌ی آلمانی سطح A2.1. با Next.js ساخته شده و خروجی آن کاملاً استاتیک است.

اپ فقط برای گوشی و نمایشگر iPhone 13 با عرض ۳۹۰ پیکسل طراحی شده است. روی صفحه‌ی بزرگ‌تر هم در ستونی با همان عرض نمایش داده می‌شود.

## اجرا

```bash
npm install
npm run dev        # حالت توسعه روی http://localhost:3000
npm test           # آزمون منطق برنامه و فایل‌های محتوا
npm run build      # ساخت خروجی استاتیک در پوشه‌ی out
npm run preview    # نمایش خروجی ساخته‌شده
```

## ساختار برنامه

برنامه در `src/lib/plan.ts` ساخته می‌شود و ۴۹ روز است، از ۱۲ آبان تا ۳۰ آذر ۱۴۰۵: سه دور ۱۳روزه‌ی کتاب Starten wir! A2 و ده روز آمادگی آزمون ÖSD Zertifikat A2.

- هر روز یک درس. بخش‌های Kursbuch از فهرست کتاب در `src/data/curriculum.ts` می‌آیند و هر بخش فعالیت مستقل است.
- کنار آن Arbeitsbuch، Grammatik و Deutsch Üben.
- روز بعد از هر سه درس، مرور به همان روز اضافه می‌شود. روزهای ۱۳، ۲۶ و ۳۹ فقط مرور است.
- شماره صفحه‌ها از کتاب چاپی است و هر بخش دو صفحه دارد.
- مدت فعالیت‌ها برآورد است و از ثابت `MINUTES` در همان فایل تغییر می‌کند.

## متن درس‌ها

هر درس یک فایل دارد: `public/content/lektion-01.json` تا `lektion-12.json`. فیلد `guide` خلاصه‌ی فارسی هر بخش کتاب و چند عبارت کوتاه کلیدی است. جمله‌ها برای تمرین و با لغات هر درس نوشته شده‌اند و متن کتاب نیستند. هر جمله با `section` به بخش درس و هر لغت با `topic` به یکی از موضوع‌های Wortschatz فهرست وصل است.

برای باز شدن مستقیم صفحه‌های کتاب، PDF خودت را با نام `public/book/kursbuch.pdf` بگذار. این پوشه در `.gitignore` است و نباید منتشر شود، چون کتاب دارای حق نشر است.

برای افزودن صوت، فایل را در `public/audio/` بگذار و مسیرش را در فیلد `audio` بنویس، مثلاً `"audio": "audio/lektion-05.mp3"`.

پس از تغییر فایل‌های محتوا، شماره‌ی `CACHE` را در `public/sw.js` بالا ببر تا نسخه‌ی نصب‌شده تازه شود.

## ذخیره‌سازی

پیشرفت در حافظه‌ی مرورگر ذخیره می‌شود. برای داشتن آن روی چند دستگاه، در داشبورد یک مخزن خصوصی و توکن fine-grained با دسترسی نوشتن Contents فقط روی همان مخزن وارد کن. پیشرفت در فایل `fahrplan-progress.json` آن مخزن ذخیره می‌شود و توکن فقط در مرورگر همان دستگاه می‌ماند.

## انتشار روی GitHub Pages

۱. در گیت‌هاب یک مخزن Public بدون README بساز.
۲. در Settings > Pages منبع را GitHub Actions انتخاب کن.
۳. کد را به شاخه‌ی `main` بفرست:

```bash
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

فایل `.github/workflows/deploy.yml` تست، ساخت و انتشار را انجام می‌دهد و مسیر سایت را از نام مخزن می‌گیرد. اپ روی `https://USERNAME.github.io/REPO/` باز می‌شود. سپس در Safari آیفون از منوی اشتراک، Add to Home Screen را بزن.

PDF کتاب‌ها در گیت نمی‌رود، پس نسخه‌ی منتشرشده لینک باز کردن PDF ندارد و فقط شماره صفحه را نشان می‌دهد.
